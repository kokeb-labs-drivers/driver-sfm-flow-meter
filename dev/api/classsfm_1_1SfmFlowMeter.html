Detailed Description

template<I2cPort Port, uint32_t FamilyMask = kAllFamilies>
class sfm::SfmFlowMeter< Port, FamilyMask >

The driver.

Template Parameters
PortYour port class, derived from I2cInterface<Port>.
FamilyMaskThe protocol families the object may drive (kFamilySf06 | ...); a configuration outside the mask is Unsupported. The default is every family.

◆ ReadRawReply()

template<I2cPort Port, uint32_t FamilyMask = kAllFamilies>
Result< RawReply > sfm::SfmFlowMeter< Port, FamilyMask >::ReadRawReply ( )
noexcept

One raw read of the running measurement: the CRC-checked words, with no decoding, no status check and no range check. The single-shot raw access for bring-up and diagnostics; GetLastReply() returns it again without I/O. A failed read does not count towards the SF05 error limit, and a silent sensor is never reported here (NoData for ever): only ReadSample() reports DeviceReset.

Returns
The words, or NotInitialized, Busy, StateUnknown, NoData, Crc, InvalidReply, Bus, Timeout.

Read the sensor temperature by a pointer sequence while measuring (parts that offer it); the SF05 family needs 5 ms between the pointer and the read, so this returns a wait. The value is GetTemperature() once the operation ended without an error.
