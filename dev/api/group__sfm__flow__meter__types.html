◆ Error

enum class sfm::Error : uint8_t
strong

Why a call failed. Every call of the driver returns one of these in its Result.

Values 0 to 9 are the shared base set; chip-specific values start at 16. [[nodiscard]] on the type: a function that returns a bare Error cannot have it ignored either (KB-CPP20-037).

Enumerator
Ok 

The call succeeded.

NotInitialized 

EnsureInitialized() has not succeeded, or Deinitialize() ran since.

InvalidArgument 

An argument or a Config field is out of range; nothing was sent.

Bus 

A write hook returned false.

Timeout 

A bounded wait or poll ended: wake, reset, stretched read.

DeviceIdMismatch 

The product identifier is not the configured part (or a prototype).

Crc 

A received word failed its CRC-8; the whole transfer was discarded.

Busy 

The call is not allowed in the current mode, or a wait is pending.

DeviceFault 

The scaling the sensor reports differs from the part's datasheet value.

Unsupported 

The part, the port hook or the family mask does not offer this call.

NoData 

The read header was NACKed: no new sample yet (or the sensor is idle).

NoDevice 

The address is not acknowledged on a write, a poll or initialisation.

OutOfRange 

A flow or temperature outside the part's span plus margin.

StatusMismatch 

The status word does not describe the measurement the driver started.

Stale 

The sample may not be fresh enough (settling, smoothing or age).

DeviceReset 

The measurement is over (the sensor reset, or was silent for the whole bound): idle again.

StateUnknown 

A failed command left the chip's mode unknown; initialise again.

InvalidReply 

A CRC-valid reply the sensor cannot send (stuck line, reserved value).

◆ Family

enum class sfm::Family : uint8_t
strong

The command-set family of a part. One protocol policy per family; every part is a row of data that names its family.

Enumerator
Sf06 

SFM4300, SFM3003, SFM3013, SFM3019, SFM3119: 16-bit commands, 9-byte frame.

Sf06Gen2 

SFM3304: SF06 framing, one gas, optional filter argument, status with averaging.

Sf06Dual 

SFM3505: two 24-bit flows (air and oxygen) in one frame.

Sf05 

SFM3000, SFM3200, SFM3300, SFM3400, SFM4200: pointer registers, 5 V.

Sf04 

SFM4100: 8-bit commands, clock-stretching read, one gas per address.

Sfx6000 

SFM6000D: preliminary vendor protocol (every fact tagged [P] in the docs).

◆ ScalingCheck

enum class sfm::ScalingCheck : uint8_t
strong

What ReadScaling() does when the sensor's scale or offset differs from the datasheet.

Enumerator
Strict 

Any difference or a wrong unit is DeviceFault.

Lenient 

A scale within 1 % of the table is accepted; offset and unit still checked.

Off 

The sensor's values are used; only scale 0 and the unit are checked.
