Detailed Description

SFM flow meter driver: the one header to include.

Copyright
Copyright (c) 2026 The driver-sfm-flow-meter authors. SPDX-License-Identifier: MIT

sfm::SfmFlowMeter<Port> drives one Sensirion SFM mass flow meter (SFM3000 to SFM6000D) through a platform port you write (see sfm_flow_meter_i2c_interface.hpp). The driver has no platform code, allocates nothing, throws nothing, takes no lock and is not thread-safe: give each object one owner, or guard it with one mutex.

Every operation is a bounded plan of bus steps. A plan that has to wait (a reset, a first sample, a wake) returns the wait to you as Result<Wait>; delay that long and call Poll(). With a DelayUs hook, AwaitPending() does that for you. ReadSample() and ReadTemperature() never wait.
