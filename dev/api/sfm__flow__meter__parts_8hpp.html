Detailed Description

The table of supported parts: one row of data per variant, the lookups, Validate() and the unit conversions.

A part is a row of data (PartInfo): family, addresses, scale and offset per gas, temperature scale, timings, feature flags, connector. The driver's code never names a part: it dispatches on PartInfo::family and on the feature flags of the row. static_asserts walk the table at build time, and pin one row per family against hand-typed datasheet values, so a mistyped digit fails the build and not a bench.

Rows of the Sfx6000 family come from an interface reference the vendor marks "preliminary": PartInfo::preliminary is true and every fact of those rows is tagged [P] in the docs.
