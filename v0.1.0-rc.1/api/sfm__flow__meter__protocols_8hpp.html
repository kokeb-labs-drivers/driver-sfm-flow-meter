Detailed Description

The six protocol policies: pure constexpr functions that turn an operation into a Plan of bus steps and decode what the sensor sent back. No I/O, no state.

The driver core runs a Plan one step at a time (it never blocks) and hands the bytes it received to a decoder. Every decoder reads the bytes through ParseWords(), the only code that reads raw bytes: it checks the CRC-8 of every word before any value is decoded (invariant I1). The dispatch is on PartInfo::family and on feature bits, never on a variant.
