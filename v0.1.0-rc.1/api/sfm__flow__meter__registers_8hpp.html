Detailed Description

Command codes, status-word helpers and the CRC-8 of the SFM flow meters.

The SF06 families and the SFx6000 have no register map: a transaction is a 16-bit command, an optional 16-bit argument with its CRC, and a read of 16-bit words that each end in a CRC-8. The SF05 family uses 16-bit pointer codes, the SF04 family 8-bit commands. The same code can mean different gases on different parts (0x3615 is nitrous oxide on the SFM4300-20, heliox on the SFM3013-300-CLM and carbon dioxide on the SFM6000D), so start codes live in the part table, never here as a gas.
