Detailed Description

Optional ESP-IDF layer: a Config built from the CONFIG_SFM_FLOW_METER_* Kconfig options.

Include this header only where you want menuconfig to choose the defaults; the driver never includes it and no driver signature depends on it. Under ESP-IDF the values come from sdkconfig.h. Without Kconfig every option falls back to the datasheet default, so KconfigDefaults() equals Config{}. The variant and the address are not options: they name the part, so the application sets them (PresetFor()).

Kconfig writes a bool option set to "n" as an absent macro, so every bool option here is off by default and an absent macro means off in both cases.

One configuration per program: the inline function below depends on the CONFIG_ macros, so every translation unit of one program must see the same values (ESP-IDF has one sdkconfig.h per build; each host test is its own program). No driver or library header includes this one (handbook KB-CPP20-018).
