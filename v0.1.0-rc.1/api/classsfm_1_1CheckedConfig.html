Detailed Description

A configuration proven valid at build time.

constexpr CheckedConfig kBoard{PresetFor(Variant::SFM3003_300_CL)}; fails to compile, naming ConfigIsInvalid, when Validate() rejects the configuration. Pass kBoard.Get() to the driver; the driver still validates at start-up, for configurations built at run time.
